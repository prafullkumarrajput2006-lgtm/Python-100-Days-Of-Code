# 100 Days of Python Programming Practice

This repository contains my **100 Days of Python programming practice work, exercises, and mini-projects** completed during the *100 Days of Code* challenge by **CodeWithHarry**.

The files include day-wise topic implementations, hands-on coding exercises, OOP concepts, file handling, automation scripts, and small Python applications. The purpose of this repository is to keep my learning progress, practice code, and hands-on examples in one place.

## 🛠️ Technologies & Modules Covered

-   Python 3
-   Built-in Modules (`os`, `time`, `shutil`, `re`, `functools`, `asyncio`, `threading`, `multiprocessing`, `random`)
-   External Libraries (`requests`, `pandas`, `pygame`, `pypdf`, `pyttsx3`, `SpeechRecognition`, `wikipedia`, `pywin32`)
-   Tkinter (GUI Development)
-   REST APIs (`NewsAPI`)

## 📚 Topics Practiced

### Core Python & Fundamentals

-   Basic `print()` statements, comments, and escape sequences
-   Variables and built-in data types (`int`, `float`, `str`, `bool`, `None`)
-   Arithmetic, comparison, assignment, logical, and bitwise operators
-   Implicit and explicit type casting
-   Taking user input (`input()`)
-   Strings, string slicing, and string methods
-   String formatting (`f-strings`)
-   Docstrings (`__doc__`) and PEP-8 guidelines

### Control Flow & Functions

-   Conditional statements (`if`, `if-else`, `elif`, nested `if-else`)
-   Short-hand `if-else` (ternary expressions)
-   `match-case` statements
-   `for` loops and `while` loops
-   `break`, `continue`, and loops with `else`
-   User-defined functions (`def`) and `return` statements
-   Function arguments (default, keyword, variable-length `*args`/`**kwargs`, required)
-   Recursion
-   Local vs. global variables (`global` keyword)

### Data Structures

-   Lists, indexing, slicing, list comprehension, and list methods
-   Tuples, immutability, and tuple operations
-   Sets and set methods (`union`, `intersection`, `difference`, etc.)
-   Dictionaries and dictionary methods (`update`, `pop`, `popitem`, `clear`)
-   `enumerate()` function

### Error Handling, File I/O & Functional Concepts

-   Exception handling (`try`, `except`, `finally`)
-   Raising custom errors (`raise` and custom `Exception` classes)
-   Virtual environments (`venv`) and `import` mechanics
-   `if __name__ == "__main__"` idiom
-   File I/O (`open`, `read`, `write`, `append`, `with` statement)
-   `readline()`, `readlines()`, `writelines()`, `seek()`, `tell()`, and `truncate()`
-   `lambda` functions
-   `map()`, `filter()`, and `reduce()`
-   `is` vs. `==` (identity vs. value equality)
-   Walrus operator (`:=`)

### Object-Oriented Programming (OOP)

-   Classes, objects, and the `self` parameter
-   Constructors (`__init__`)
-   Decorators (`@decorator`)
-   Getters and setters (`@property`)
-   Access specifiers / modifiers (Public, Protected, Private)
-   Static methods (`@staticmethod`) and class methods (`@classmethod`)
-   Class methods as alternative constructors
-   Instance variables vs. class variables
-   Single, multiple, multilevel, hybrid, and hierarchical inheritance
-   The `super()` keyword and method overriding
-   Magic / Dunder methods (`__len__`, `__str__`, `__repr__`, `__call__`)
-   Operator overloading (`__add__`)
-   Object introspection (`dir()`, `__dict__`, `help()`)

### Advanced Python & Automation

-   `os` module and `shutil` module (file and directory automation)
-   `time` module (timestamps and execution timing)
-   Command-line utilities using `argparse`
-   HTTP requests using the `requests` module
-   Generators and the `yield` keyword
-   Function caching (`functools.lru_cache`)
-   Regular expressions (`re` module)
-   Asynchronous programming (`asyncio`, `async`/`await`)
-   Multithreading (`threading`) and Multiprocessing (`multiprocessing`)

## 🚀 How to Run

### Standard Python Scripts

Install Python 3, open the project folder in a terminal, and run any day's file with:

```bash
python filename.py
```

For example:

```bash
python Day39.py
```

### Scripts with External Dependencies

For game, PDF, API, or text-to-speech scripts (`Day2.1.py`–`Day2.4.py`, `Day76.py`, `Day83.py`, `Day90.py`, `Day94.py`), install the required packages first:

```bash
pip install requests pandas pygame pypdf pyttsx3 SpeechRecognition wikipedia pywin32
```
